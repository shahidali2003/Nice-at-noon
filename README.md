🌟 Nice at Noon
A modern web project using HTML, Tailwind CSS, and GSAP for smooth animations and an elegant UI.

🚀 Overview
Nice at Noon is a stylish and interactive web page built with HTML, Tailwind CSS, and GSAP. It features smooth animations, a responsive layout, and a clean design.

✨ Features
🎬 Smooth Animations – Powered by GSAP for stunning transitions
⚡ Fast & Lightweight – Optimized for performance and speed
🎨 Modern Design – Clean, minimal, and visually appealing
🛠 Tech Stack
HTML5 – Markup structure
Tailwind CSS – Styling & responsiveness
GSAP (GreenSock) – Advanced animations
